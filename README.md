# AutoPoster

Desktop- и веб-приложение для публикации в VK, Instagram, Telegram и MAX.

[Скачать AutoPoster для Windows](https://github.com/code-spark-pro/single/releases/latest/download/AutoPoster.exe)

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

Настройки, токены, база и логи сохраняются в `%LOCALAPPDATA%\AutoPoster`. Для Instagram локальные файлы должны быть доступны Graph API по публичному HTTPS-адресу. Укажите адрес туннеля, направленного на порт `8080`, в настройке «Публичный URL медиа».

### ВКонтакте

Используется личный токен пользователя от standalone-приложения с правами `wall` и `photos`. Нажмите «Получить токен», разрешите доступ и вставьте итоговый URL из адресной строки обратно в приложение. Также можно вставить готовый личный токен отдельной кнопкой. ID группы указывается положительным числом без `-`; пользователь должен иметь право публикации в группе.

### Сеть

В настройках доступны системный режим, прямое подключение и собственный HTTP/HTTPS/SOCKS5-прокси. Кнопка «Проверить сеть» отдельно проверяет endpoint-ы VK, Instagram, Telegram и MAX. Если Telegram или Facebook заблокированы провайдером, выберите «Свой прокси» и укажите, например, `socks5://127.0.0.1:1080` либо адрес вашего прокси-сервера.

### MAX

Создайте бота в [MAX для бизнеса](https://business.max.ru/self), добавьте его в канал или чат и выдайте право публикации. Укажите токен бота и числовой `chat_id`. Используется официальный API `platform-api2.max.ru`; поддерживаются текст, JPG, PNG, GIF и MP4.

## Сайт и веб-панель

Задайте пароль администратора и запустите сервер:

```powershell
$env:AUTOPOSTER_WEB_PASSWORD = "сложный-пароль"
python web_main.py
```

Локальный адрес: `http://127.0.0.1:8000`. Главная страница доступна публично и содержит кнопку загрузки `dist\AutoPoster.exe`; веб-панель защищена паролем. Для постоянной публичной ссылки разверните `Dockerfile` на VPS или облачном сервисе, подключите HTTPS-домен и задайте переменные `AUTOPOSTER_WEB_PASSWORD`, `AUTOPOSTER_WEB_SECRET` и `AUTOPOSTER_COOKIE_SECURE=1`. Каталог `/data` необходимо подключить как постоянный volume.

После развёртывания укажите полученный HTTPS-адрес в поле «Публичный адрес сайта». Кнопка «Открыть сайт» в верхней панели desktop-приложения будет открывать этот адрес.

## Массовая загрузка

Вкладка «Массовая загрузка» принимает CSV или JSON. Поля: `text`, `media_paths`, `platforms`, `scheduled_at`. В CSV несколько файлов и платформ разделяются `;`, время задаётся в ISO 8601. Пример:

```csv
text,media_paths,platforms,scheduled_at
Первый пост,C:\media\photo.jpg,vk;telegram;max,2026-09-24T12:30
```

Удаление записи из истории не удаляет уже опубликованный пост из социальной сети.

## Сборка

```powershell
pyinstaller --clean autoposter.spec
```

Готовый файл появится в `dist\AutoPoster.exe`. Приложение не требует административных прав.
