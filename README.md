# Окно в другой мир

Desktop- и веб-приложение для публикации в VK, Одноклассники, Instagram, Telegram и MAX.

Изображения JPG, PNG, GIF, WebP, HEIC, HEIF, AVIF, BMP и TIFF автоматически приводятся к совместимому с API формату, включая поворот EXIF, цветовой режим и ограничения Instagram.

[Скачать приложение для Windows](https://github.com/code-spark-pro/single/releases/latest/download/Okno-v-drugoi-mir-safe.zip)

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

Настройки, токены, база и логи сохраняются в `%LOCALAPPDATA%\AutoPoster`. Для Instagram локальные файлы должны быть доступны Graph API по публичному HTTPS-адресу. Укажите адрес туннеля, направленного на порт `8080`, в настройке «Публичный URL медиа».

### ВКонтакте

Используется личный токен пользователя с правами `wall` и `photos`. В веб-кабинете можно вставить готовый `access_token` напрямую. Альтернативный OAuth-вход требует ID и защищённый ключ приложения: браузер получает одноразовый код, а сервер обменивает его на токен. ID группы указывается положительным числом без `-`; пользователь должен иметь право публикации в группе.

### Сеть

В настройках доступны системный режим, прямое подключение и собственный HTTP/HTTPS/SOCKS5-прокси. Кнопка «Проверить сеть» отдельно проверяет endpoint-ы VK, Одноклассников, Instagram, Telegram и MAX. Если Telegram или Facebook заблокированы провайдером, выберите «Свой прокси» и укажите, например, `socks5://127.0.0.1:1080` либо адрес вашего прокси-сервера.

### Одноклассники

Создайте OAuth-приложение OK и укажите Application ID, публичный и секретный ключи, постоянный `access_token`, `session_secret_key` и числовой ID группы. Для текстовых публикаций приложению нужны права `GROUP_CONTENT` и `VALUABLE_ACCESS`; для публикации фотографий дополнительно требуется `PHOTO_CONTENT`. Публикация выполняется сервером через официальный метод `mediatopic.post`, секреты не выводятся в кабинете и не сохраняются в браузере.

### MAX

Создайте бота в [MAX для бизнеса](https://business.max.ru/self), добавьте его в канал или чат и выдайте право публикации. Укажите токен бота и числовой `chat_id`. Используется официальный API `platform-api2.max.ru`; поддерживаются текст, JPG, PNG, GIF и MP4.

## Сайт и веб-панель

Задайте логин и пароль администратора, затем запустите сервер:

```powershell
$env:AUTOPOSTER_WEB_USERNAME = "Admin"
$env:AUTOPOSTER_WEB_PASSWORD = "сложный-пароль"
python web_main.py
```

Локальный адрес: `http://127.0.0.1:8000`. Главная страница доступна публично и содержит кнопку загрузки `dist\Okno-v-drugoi-mir-safe.zip`; веб-панель защищена логином и паролем. Для постоянной публичной ссылки разверните `Dockerfile` на VPS или облачном сервисе, подключите HTTPS-домен и задайте переменные `AUTOPOSTER_WEB_USERNAME`, `AUTOPOSTER_WEB_PASSWORD`, `AUTOPOSTER_WEB_SECRET` и `AUTOPOSTER_COOKIE_SECURE=1`. Каталог `/data` необходимо подключить как постоянный volume.

Если переменные Render ещё не заданы, приложение допускает временный пароль, сохранённый локально в игнорируемом файле `.env.render`; в репозиторий включён только его SHA-256 хеш. После первого входа обязательно задайте новый `AUTOPOSTER_WEB_PASSWORD` в Render.

После развёртывания укажите полученный HTTPS-адрес в поле «Публичный адрес сайта». Кнопка «Открыть сайт» в верхней панели desktop-приложения будет открывать этот адрес.

## Массовая загрузка

Вкладка «Массовая загрузка» принимает CSV или JSON. Поля: `text`, `media_paths`, `platforms`, `scheduled_at`. В CSV несколько файлов и платформ разделяются `;`, время задаётся в ISO 8601. Пример:

```csv
text,media_paths,platforms,scheduled_at
Первый пост,C:\media\photo.jpg,vk;telegram;max,2026-09-24T12:30
```

Удаление записи из истории не удаляет уже опубликованный пост из социальной сети.

## Сборка

```powershell
pyinstaller --clean autoposter.spec
```

Готовая папка появится в `dist\Okno-v-drugoi-mir`. Сборка не использует UPX и однофайловую самораспаковку. Для распространения упакуйте папку целиком: после распаковки запускается `Okno-v-drugoi-mir.exe`, а каталог `_internal` должен оставаться рядом. В заголовке окна отображается название «Окно в другой мир». Приложение не требует административных прав.
