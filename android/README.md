# Android

Устанавливаемый Android-клиент веб-кабинета. Открывает `http://158.160.237.113/dashboard` в отдельном WebView. Для публикации и сохранения настроек нужен доступ к серверу; вход в VK в браузере не подключает кабинет автоматически. Ссылки на сторонние сайты и получение личного токена открываются во внешнем браузере.

Сборка (JDK 17, Android SDK 35, Gradle 8.10.2): `gradle -p android assembleDebug`. Файл для установки: `android/app/build/outputs/apk/debug/app-debug.apk`. Такой debug APK подписывается локальным отладочным ключом. Workflow `.github/workflows/android-apk.yml` также собирает APK и сохраняет его как артефакт GitHub Actions.

Кабинет сейчас работает по HTTP. При использовании с телефона данные учётной записи и токен передаются без HTTPS; перед использованием на постоянной основе нужно перевести сервер на HTTPS.
